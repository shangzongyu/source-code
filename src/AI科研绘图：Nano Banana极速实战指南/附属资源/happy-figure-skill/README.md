# Happy Figure Skill

论文逻辑已经写清楚了，图却迟迟画不出来。

提示词收藏了一堆，真正能稳定复用的没有几个。

很多时候，真正卡住科研绘图的并不是“不会写 prompt”，而是没有把论文内容、图示结构、领域视觉语言和模型约束放到同一套工作流里。

**`happy-figure-skill` 想解决的，就是从科研内容到可控绘图 prompt 之间的这一段断层。**

它不是一个简单的提示词模板库，也不是让 AI 随机发挥的万能咒语。它更像是一套面向 AI Agent 的科研绘图提示词工作流：先读懂研究内容，再判断应该画什么图、用什么视觉语言、保留哪些文字、避开哪些事实边界，最后输出一段可以直接复制给绘图模型的完整 prompt。

## 它适合解决什么问题

如果你遇到的是下面这些场景，这个 skill 就可以派上用场：

- 论文已经有摘要、方法或图注，但不知道怎么转成 Graphical Abstract。
- 想画机制图、技术路线图、实验装置图、模型架构图，却总是写成泛泛的“科技感插画”。
- 不同学科的图混在一起，计算机论文被画成生物机制图，材料体系又被画成普通流程图。
- 参考图风格很好，但不知道怎样把“风格”迁移到自己的科研内容上。
- 研究领域比较小众，现有模板覆盖不到，需要先生成一套新的领域母版。
- 想让 Agent 根据论文自动生成 prompt，而不是每次从零开始拆解图示逻辑。

需要说明的是，它只负责生成绘图 prompt，不负责直接生成图片，也不替代作者对科学事实、投稿规范和图像合规性的判断。

## 核心思路

`happy-figure-skill` 的关键不是“把论文塞给模型，让模型自由发挥”，而是把科研绘图拆成几个更可控的判断环节：

| 环节 | 要解决的问题 | 对应能力 |
| --- | --- | --- |
| 内容理解 | 这篇研究真正要表达什么？ | 从 PDF、Word、LaTeX、Markdown、图注、开题材料或纯文本中提取核心信息 |
| 领域判断 | 这张图应该属于哪种学科视觉语言？ | 区分计算机/机器学习、材料与化学、生物与医学等领域语境 |
| 图型选择 | 这次要画的是流程、机制、系统、对比，还是图形摘要？ | 使用图类型规则约束布局、模块、连接关系和失败模式 |
| 模型适配 | prompt 应该如何适配不同绘图模型？ | 轻量适配 Nano Banana Pro、Nano Banana 2、Qwen-image-2.0、gpt-image-2 等模型 |
| 文字控制 | 图中到底能出现哪些字？ | 将可见文字规则直接写入最终 prompt，避免模型乱加标签 |

这一流程的价值在于：它把“随手写一句 prompt”变成了一套可复用、可检查、可迁移的科研视觉表达方法。

## 安装

将压缩包解压后，让 AI Agent 自己完成安装：

```text
请读取 /你的解压路径/AGENT_INSTALL.md，并把这个 skill 安装到我当前使用的 Agent 环境中。
```

## 怎么使用

最简单的用法是把论文内容、文档路径或研究片段交给支持 skill 的 Agent：

```text
使用 $happy-figure-skill-zh 读取我的论文，并生成一段适合 Nano Banana Pro 的图形摘要 prompt。
```

如果你已经知道自己要画什么，可以直接说明目标：

```text
使用 $happy-figure-skill-zh，根据这段方法部分生成一个模型架构图 prompt，图中文字用英文。
```

如果你给的是 LaTeX 项目文件夹，Agent 应该先让你指定主 `.tex` 文件，而不是自己猜入口。这样做看起来多一步，但能避免读错正文、漏掉图注或把附录当成主线。

## 输出会包含什么

默认情况下，skill 会根据任务输出：

- 文档理解：说明它读到了什么、准备画什么。
- 选用依据：列出使用了哪些摘要、方法、结果或图注片段。
- 最终绘图提示词：可以直接复制给绘图模型的完整 prompt。
- 简短审查提醒：提醒你检查科学准确性、标签、数据边界和投稿要求。

当风格选择会显著影响结果时，它会先输出“出图预期确认”，让你在 2-3 个方向中选择；确认后再生成最终 prompt。

如果你只想拿到 prompt，也可以直接说“只要 prompt”。这时它会减少解释，把重点放在最终可复制内容上。

## 后续处理建议

拿到最终 prompt 并生成图片后，不建议直接把 AI 输出图当作论文终稿。对于正式投稿、长期维护或需要反复修改的插图，建议将生成结果作为构图参考，再进入人工重绘或矢量化重构阶段。

常见路径包括：

- 用 PPT、Figma、Visio 等工具参考重绘结构，适合流程图、系统架构图和逻辑关系明确的示意图。
- 用 Illustrator、Vectorizer 等工具做基础矢量化，再人工清理路径、重排文字和统一线条。
- 对规则性强的图形，可以参考生成结果，用 Matplotlib 等代码方式重建可控矢量图。

这个 skill 负责把科研内容转化为高质量绘图 prompt；最终图像是否符合投稿、署名、版权和事实准确性要求，仍需要作者完成检查、编辑和重构。

## 边界

需要特别强调的是，科研绘图不能只追求好看。

对于真实数据图、显微图、实验照片、定量结果图等事实性证据，不应让绘图模型编造、修补或改写。这个 skill 更适合生成定性示意图、机制解释图、方法框架图、图形摘要和展示型科研图示。

也就是说，它提供的是从科研逻辑到视觉表达的结构化路径，而不是替代研究者的科学判断。
